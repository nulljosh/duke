# Decompiled games for a bot

Games whose code has been decompiled, so a bot can read their state by name. Checked 2026-10-29.

Progress is as the source states it. "Not stated" means the repo README and decomp.dev gave no number. "Not captured" means only a progress badge was found. Turn-based and slow games are the easiest bot targets, so the Notes column rates each game for bot fit.
