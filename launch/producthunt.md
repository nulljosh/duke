Name (<=40 chars):
Duke

Tagline (<=60 chars):
An autopilot for games. It plays while you sleep.

Description (<=260 chars):
Duke plays Duolingo, Factorio, Game Dev Tycoon, FEZ, Papers, Please, Oxygen Not Included, Pokemon Sapphire and Pikmin 2 for real, around the clock. It reads each game's own state and acts on it. Open source under Apache 2.0.

Topics (3):
Productivity, Open Source, Developer Tools

First comment (maker story):
Duke started as a menu bar app called Cruise, then Surf, and now it is Duke, named for Duke Kahanamoku. Duolingo was the first game it played.

It reads each question's answer out of the page's own React state and clicks it. Math has no answer on the page, so Duke solves those itself. Nothing is guessed. If it sees a shape it has never seen, it logs it and skips it.

The rest of the list came later. Factorio, Game Dev Tycoon, FEZ, Papers, Please, Oxygen Not Included, Pokemon Sapphire and Pikmin 2 all run the same way, reading each game's own state. The status of every game is in games/README.md on GitHub.

It also keeps the Duolingo streak alive. After 6pm with no XP today, it finishes a language lesson. It starts at login and comes back on its own after a crash.

I want to be straight about one thing. Automating Duolingo is against their terms and can get an account banned. This is a personal study, not a product.

The code is Apache 2.0. Questions are welcome in the comments.
